# Instrucciones de Kalkú

## Dirección visual

- Antes de crear o modificar personajes, objetos, escenarios, iconos o interfaz, leer `assets/ART-DIRECTION.md` y observar las imágenes de referencia pertinentes. La guía se aplica también cuando la petición solo nombre un objeto y no repita el estilo.
- Mantener la identidad de Kalkú: caricatura de aventuras inspirada en animación tradicional de los años 80, reinterpretada con un acabado digital limpio, cálido y expresivo.
- Usar los assets existentes como referencia visual directa. Para generar imágenes, adjuntar las referencias pertinentes mediante la herramienta de imágenes; un prompt textual por sí solo no basta para mantener la continuidad.
- Para un mundo con guía propia, leer también su `ART-DIRECTION.md`. Las guías de mundo precisan temática y materiales dentro del estilo general.
- Resolver las decisiones visuales rutinarias con la guía. Una petición futura de un objeto nuevo hereda esta estética, salvo que el usuario pida explícitamente otra.
- No sustituir imágenes existentes por el solo hecho de que difieran ligeramente de la guía: las mejoras se aplican a nuevos assets y a las revisiones solicitadas.
- Si se incorpora un asset nuevo, comprobar su legibilidad al tamaño de uso, encuadre, transparencia cuando corresponda y coherencia con las referencias. Registrar en su archivo de prompt las referencias usadas y las decisiones relevantes.

Las instrucciones explícitas del usuario tienen prioridad sobre estas convenciones.
